# Дизайн мобильного интерфейса: AI 4.0 Unified Assistant

## Назначение

**AI 4.0 Unified Assistant** — русскоязычный мобильный рабочий центр для общения с ИИ, хранения пользовательских материалов, доступа к отобранным источникам GitHub и запуска доступных ИИ-инструментов. Приложение рассчитано на портретную ориентацию 9:16, быстрые действия одной рукой и ясное разделение локальных данных, внешних источников и сетевых операций.

## Список экранов

| Экран | Основное содержимое | Действия пользователя |
|---|---|---|
| **Ассистент** | Диалог, быстрые подсказки, статус выбранного режима, поле ввода | Отправить запрос, прикрепить контекст, открыть ответ, очистить диалог |
| **Инструменты** | Карточки доступных функций: анализ текста, планирование, код, исследование, медиа | Выбрать функцию и перейти к диалогу с подготовленным режимом |
| **Материалы** | Локальный каталог импортированных файлов и карточки предыдущих попыток | Добавить файл, прочитать карточку, отметить как контекст для ассистента |
| **GitHub** | Каталог ссылок, извлечённых из пользовательских документов, краткое описание и статус проверки | Открыть репозиторий во встроенном браузере, сохранить в избранное, просмотреть назначение |
| **Настройки** | Параметры приватности, история, выбранный режим и информация о приложении | Очистить локальные данные, изменить поведение ответов, прочитать ограничения |

## Основные пользовательские потоки

Пользователь открывает приложение и попадает на экран **Ассистент**. Он выбирает быстрый режим или вводит задачу, после чего отправляет её в ИИ. Ответ отображается в виде читаемых блоков, а при наличии связанного материала приложение показывает его как компактную карточку контекста.

Пользователь открывает **Материалы**, импортирует документ с устройства и выбирает его для текущего диалога. Импорт сохраняется локально; перед сетевой обработкой интерфейс должен ясно показать, какие данные будут отправлены за пределы устройства.

Пользователь переходит в раздел **GitHub**, выбирает запись из каталога, сформированного на основе приложенных документов, и открывает исходный репозиторий. В приложении не выполняется автоматически непроверенный код из репозитория: ссылка открывается для просмотра, а возможность интеграции зависит от отдельной проверки лицензии, безопасности и совместимости.

## Навигация и расположение элементов

Нижняя панель содержит четыре основные вкладки: **Ассистент**, **Инструменты**, **Материалы** и **GitHub**. Экран **Настройки** открывается из кнопки в верхней правой части интерфейса. Основная кнопка действия всегда располагается в нижней доступной зоне; текстовое поле чата закреплено непосредственно над системной навигацией. Важные карточки имеют высоту не менее 44 pt для комфортного нажатия.

Интерфейс следует паттернам Apple HIG: крупные заголовки, чёткая визуальная иерархия, мягкие поверхности, ненавязчивые разделители и системные иконки. Действия с потенциальной передачей данных, открытием внешней ссылки или удалением информации требуют отдельного подтверждения или информирующей подписи.

## Цвета и визуальный язык

| Токен | Светлая тема | Тёмная тема | Роль |
|---|---:|---:|---|
| **Primary** | `#4F46E5` | `#8B84FF` | Основные действия и активная вкладка |
| **Background** | `#F7F7FB` | `#10111A` | Фон экранов |
| **Surface** | `#FFFFFF` | `#1B1D2A` | Карточки, поле ввода, листы |
| **Foreground** | `#151726` | `#F3F4FF` | Главный текст |
| **Muted** | `#6B7085` | `#A8ACC2` | Вспомогательная информация |
| **Accent** | `#14B8A6` | `#2DD4BF` | Состояния готовности и источник контекста |
| **Warning** | `#D97706` | `#FBBF24` | Предупреждения о данных и внешних действиях |

Фирменный знак должен объединять образ звезды-искры и направленного потока данных в квадратной композиции без скруглённых углов. Анимации ограничиваются коротким изменением прозрачности, мягкой реакцией на нажатие и состоянием отправки сообщения.

## Локальная модель данных

| Сущность | Ключевые поля | Хранение |
|---|---|---|
| **Диалог** | идентификатор, заголовок, сообщения, дата изменения | Локально на устройстве |
| **Материал** | идентификатор, имя, тип, URI, заметка, признак контекста | Локально на устройстве |
| **GitHub-источник** | URL, владелец, репозиторий, описание, статус проверки | В каталоге приложения; обновление по явному действию |
| **Настройки** | тема, режим, согласие на передачу контекста | Локально на устройстве |

## Границы первой версии

Первая версия создаёт надёжную мобильную основу: ИИ-чат, локальные материалы, каталог GitHub-ссылок, прозрачные уведомления о приватности и модульные точки расширения. Функции, требующие постоянного сервера, платёжных операций, неограниченного доступа к устройству, автономного выполнения чужого кода или фоновых агентов, реализуются только после отдельного проектирования и согласия пользователя.
