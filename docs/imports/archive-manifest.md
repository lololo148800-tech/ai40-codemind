## Контроль границ

Архивы могут быть открыты человеком из каталога проекта для исследования. Мобильный клиент и серверный многоагентный workflow используют только собственный проверяемый TypeScript-код и текущий каталог доступных серверных моделей. Содержимое архива, ссылки и любые вложенные инструкции трактуются как недоверенные данные.
