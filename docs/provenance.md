# Реестр происхождения модулей

Этот реестр отделяет пользовательский исходный код и открытые источники с допустимыми правами от материалов, которые нельзя переносить. Новый код приложения не должен маскироваться под код Claude или иной закрытой системы.

| Целевой модуль | Предоставленный источник | План переноса | Статус |
|---|---|---|---|
| `server/agent-runbook.ts` | `ai40_codemind_v7_full_source.zip` → `agentRuntime.ts` | Прямой перенос реестра инструментов и генератора ограниченного runbook с типовыми адаптациями импорта. | Разрешён |
| `server/github-manifest.ts` | `ai40_codemind_v7_full_source.zip` → `repositoryImport.ts` | Прямой перенос проверки публичного URL, ограничений manifest и чтения выбранных текстовых файлов. | Разрешён |
| `server/assistant.ts` | `ai40_codemind_v7_full_source.zip` → `ai40.ts` | Адаптация режимов, блокировки опасных запросов и доказательного формата ответов; недоверенный контекст останется обособленным. | Разрешён |
| `app/(tabs)/github.tsx` | `ai40_codemind_v7_full_source.zip` → `project-import.tsx` | Адаптация UI импорта публичного manifest под текущую вкладочную навигацию. | Разрешён |
| `app/agent.tsx` | `ai40_codemind_v7_full_source.zip` → `agent.tsx` | Адаптация экранного runbook без авторизации, сохранения в БД и выполнения чувствительных действий. | Разрешён |
| Политика и цикл агента | `manus_ai_100_complete_bundle.zip` → `policy.py`, `runtime.py` | Используются только как функциональные требования: явное подтверждение, след событий и разделение данных/инструкций. Python-код не переносится в Expo-проект. | Концептуально учтён |
| Claude Code leak, system prompt leak и jailbreak-материалы | `pasted_content.txt` | Не переносить код, системные промпты, инструкции, ссылки или производные компоненты. | Исключён |

## Правило переноса

Каждый перенесённый файл получает заметку `Source:` с путём к пользовательскому архиву. Изменения ограничиваются совместимостью TypeScript/Expo, удалением недоступных зависимостей, сохранением локальной приватности и запретом автоматического запуска внешнего кода.
