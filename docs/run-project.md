# Запуск AI40 CodeMind

## Что находится в проекте

**AI40 CodeMind** — Expo/React Native приложение с серверным многоагентным анализом. Оно хранит импорт `Mega AI Bot v3` в `docs/imports/mega-ai-bot-v3-reference.py` как справочный файл и использует динамически доступный серверный каталог моделей. Импорт не запускается и не выдаётся за источник гарантированных возможностей.

## Быстрый запуск в среде проекта

В панели проекта откройте **Preview**. На Android установите **Expo Go**, отсканируйте отображённый QR-код и откройте проект на телефоне. Затем выберите **Инструменты** → **Многоагентный coding workflow**, введите цель, при необходимости вставьте небольшой фрагмент кода или лог, выберите режим и подтвердите запуск анализа. API-ключ на телефоне не требуется: запросы идут через серверный шлюз приложения.

## Локальный запуск для разработки

Требуются Node.js 22+ и pnpm 9+. В каталоге проекта выполните:

```bash
pnpm install
pnpm dev
```

Для статических проверок используйте:

```bash
pnpm check
pnpm lint
pnpm test
```

Мобильный клиент запускается в Expo Go через QR-код из консоли/панели, а web-preview удобен для просмотра маршрутов и базовой вёрстки. Для Android-устройства нужны один Wi-Fi/маршрут между устройством и dev server либо tunnel, который предоставляет Expo.

## Сборка Android APK

Текущий интерфейс **готовит план APK и release quality gate**, но не собирает APK на телефоне и не запускает shell-команды автоматически. Для реальной сборки добавьте проверенный CI workflow или изолированный worker с явно ограниченными командами Gradle/EAS. Перед этим проверьте `app.config.ts`, Android package, подпись релиза, переменные окружения CI и прохождение `pnpm check`, `pnpm lint`, `pnpm test`.

## Границы данных

Отправляйте на многоагентный анализ только те фрагменты, логи и ссылки, которые готовы передать серверному AI-сервису. Не вставляйте пароли, API-ключи, cookies, приватные URL или чужие персональные данные. Публичные ссылки являются недоверенным контекстом; приложение не обходит авторизацию, paywall, CAPTCHA или другие средства защиты.
