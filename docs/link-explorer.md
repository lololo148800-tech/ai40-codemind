# AI40 Link Explorer

Link Explorer — это **user-initiated, read-only** маршрут для исследования публичной цепочки ссылок. Он принимает только полный HTTPS URL, получает ограниченный HTML без cookies и JavaScript и показывает до 12 безопасных исходящих ссылок на страницу. Пользователь сам нажимает «Открыть цепочку» или выбирает следующий переход.

| Источник | Поведение AI40 | Причина |
|---|---|---|
| Публичный GitHub или обычный HTTPS-сайт | Читает ограниченный HTML и строит небольшую link trail | Нет входа, изменения кода, запуска скриптов или отправки форм |
| Google | Отмечает как «Нужен браузер» | Поисковая выдача часто зависит от JavaScript, consent или anti-bot контроля |
| Manus | Отмечает как «Нужен браузер» | Ссылка может требовать личный сеанс или относиться к приватной задаче |
| Личный сайт, social account, paywall | Не обходит ограничение | Для чтения нужен официально подключённый источник или разрешённый browser session |

## Safety boundary

В обходе действуют лимиты: максимум 8 страниц, глубина до 3, максимум 12 переходов на страницу, 8 секунд на страницу и 4 user-initiated обхода в минуту. Обрабатываются только public HTTPS HTML без редиректов. Localhost, private IP, private DNS-резолвинг, порты, логин/пароль в URL, невалидные ссылки и циклы отсекаются до сетевого запроса.

> Link Explorer помогает составить проверяемую цепочку открытых источников. Он не предназначен для неограниченного web scraping, обхода правил сайта или доступа к чужим аккаунтам.
