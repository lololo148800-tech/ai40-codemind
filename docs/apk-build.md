# Получение Android APK

Проект подготовлен для сборки Android-приложения. В рабочей среде не выполняется ручная сборка APK: она требует ресурсов, которые не предназначены для локального запуска в этом проекте.

Чтобы получить APK, откройте панель проекта, нажмите **Publish** и запустите публикацию. После успешной облачной сборки в интерфейсе появится результат, из которого можно скачать Android APK. Перед публикацией уже сохранен контрольный снимок проекта, поэтому Publish будет доступен в панели управления.

## Что будет включено в APK

| Раздел | Состояние |
|---|---|
| ИИ-ассистент с режимами вопрос, код, исследование и создание | Реализован |
| Локальная история и настройки | Реализованы |
| Импорт локальных материалов и контролируемая передача текстового контекста | Реализованы |
| Каталог разрешённых GitHub-источников | Реализован |
| Автоматический запуск внешнего кода, клонирование и публикация репозиториев | Намеренно отключены |

После установки проверьте на устройстве отправку обычного вопроса, импорт небольшого текстового файла, включение контекста в настройках и открытие ссылки из GitHub-каталога.
