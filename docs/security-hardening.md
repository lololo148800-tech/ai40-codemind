# Защита исходного кода AI40 CodeMind

## Реальная модель защиты

Ни одна защита не делает код, выполняемый на устройстве пользователя, математически нечитаемым. Expo/React Native bundle можно извлечь и анализировать, а Python-обфускация повышает стоимость реверс-инжиниринга, но не заменяет защиту секретов или серверную авторизацию. Поэтому AI40 CodeMind использует server-first подход: логика выбора моделей, лимиты, prompt-шаблоны и ключи остаются в серверной части, а мобильный клиент получает только UI и результаты API.

| Слой | Контроль | Назначение |
|---|---|---|
| Мобильный клиент | Не хранит API-ключи и не содержит server prompts | Не дать извлечь секреты из APK |
| tRPC server | Zod-валидация длины цели и контекста | Не допустить неограниченный input в модель |
| Multi-agent endpoint | In-memory ограничение: до 3 запусков панели за 60 секунд на IP-ключ процесса | Сдержать случайный fan-out и простое злоупотребление |
| AI-инструкции | Запрет выдачи внутренних исходников и закрытых prompt-шаблонов | Не превратить chat в канал экспорта кода |
| Репозиторий | Private access, review, CI и правила секретов | Защитить исходники на уровне поставки |

## PyArmor — только для Python agent.py

PyArmor применяется только к отдельному распространяемому Python-агенту, например к архивному `agent.py`. Он не обфусцирует Expo TypeScript, Android APK или server TypeScript. Скрипт `scripts/protect-python-agent.sh` явно требует путь к входному Python-файлу и создаёт отдельный каталог дистрибутива:

```bash
bash scripts/protect-python-agent.sh /absolute/path/to/agent.py ./dist-protected-agent
```

Скрипт устанавливает PyArmor, выполняет `pyarmor gen --obf-code 2 --mix-str` и сохраняет runtime вместе с обфусцированным скриптом. Нужно распространять **весь** каталог output и тестировать его на целевой версии Python и платформе: generated runtime зависит от них.[1]

Не добавляйте API-ключи, private prompt-данные или пароли в `agent.py` до обфускации. Секреты должны приходить через server-side environment или безопасный secret manager. Привязка к устройству, срок действия и расширенные режимы PyArmor зависят от платформы и лицензии; применяйте их только после отдельного релизного теста.[1]

## Что не следует делать

Кастомный bytecode, каскадное шифрование строк и hidden runtime не спасают секрет, если ключ расшифровки доставлен в тот же APK или Python-дистрибутив. Не пытайтесь скрывать секреты только обфускацией и не запускайте неизвестный код из импортированных архивов. Внешние ZIP-пакеты в `docs/imports/archives/` остаются справочными, неисполняемыми данными.
