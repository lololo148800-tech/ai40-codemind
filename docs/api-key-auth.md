# API-key аутентификация AI40 CodeMind

AI40 использует собственные ключи для обращения к многоагентной панели. Ключ связан с владельцем, имеет единственный scope `agent:run`, хранится на сервере только как HMAC-SHA-256 хеш и может быть отозван в любой момент. Полный секрет возвращается только при выпуске и больше не доступен через приложение или базу данных.

## Жизненный цикл

| Операция | Где выполняется | Результат |
|---|---|---|
| Выпуск | Экран «Настройки» → «Управлять API-ключами», после входа в проект | Пользователь видит секрет один раз и сохраняет его в менеджере секретов |
| Использование | `X-API-Key: ai40_live_…` или `Authorization: Bearer ai40_live_…` | tRPC `agent.runPanel` проверяет хеш, отзыв и scope |
| Отзыв | Тот же экран, с destructive confirmation | `revokedAt` блокирует дальнейшее использование |

Не добавляйте API-ключ в APK, Expo public env, Git, chat, screenshot или исходный код. Для вызова из CI храните ключ в защищённом secret store CI. Технический антиабьюз-ограничитель остаётся включённым: он не является пользовательской квотой, а предотвращает случайный и неавторизованный fan-out десяти моделей.
