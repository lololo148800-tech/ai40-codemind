# AI40 Test Lab

Test Lab делает две проверяемые вещи: строит allowlisted runbook для выбранного стека и разбирает **только вставленный пользователем** stdout/stderr. Он не открывает локальные файлы, не запускает shell, не собирает APK и не объявляет тесты пройденными без evidence.

| Стек | Подготовленные проверки | Где реально выполняются |
|---|---|---|
| Expo / Node | `pnpm check`, `pnpm lint`, `pnpm test` | Одобренный GitHub Actions workflow или isolated worker |
| Python | `python3 -m py_compile <target.py>`, `python3 -m pytest` | Одобренный CI/worker после проверки зависимостей |
| Другой | Сначала обнаружение documented project command | Только после явного allowlist и approval |

Каждый реальный run должен вернуть commit SHA или версию исходников, точную команду, exit code, stdout/stderr, время и ссылки на артефакты. Это отличает настоящий результат от текста, похожего на лог.

## Размер

На 27 августа 2026 года исходное дерево AI40 без `.git` и `node_modules` занимало около **4.3 MB**; отслеживаемые исходники — около **4.0 MB**. Это не размер APK. Размер Android-пакета можно подтвердить только отдельной release-сборкой с конкретным ABI, ресурсами и включёнными нативными модулями.
